# Aryan Mishra — Portfolio

Welcome to my personal portfolio website! 🚀

Explore my projects, skills, certificates, and work in one place.

🌐 **Live Website:** [https://abhay2832.github.io/Aryanportfolio/)

## Built With
- React
- Vite
- JavaScript
- CSS

## Run on Your PC

```bash
npm install
npm run dev
```

## Edit Your Content
- `src/data.js` — skills, projects, certificates, email, and other portfolio content.
- `public/` — photos, songs, and resume files.
- `public/certificates/` — certificate images.

## Deploy
The website is deployed using GitHub Actions and GitHub Pages.
